# livemap
MVP

1. "COVER" page will direct the user to a "Choice" page. 
 - Click on login will open a "Login" page. 
 - Click on sign up opens "pre sign up" page, where user chooses if they want to register a personal account or business account. Then it will open a "Sign up" page. 
- Click on explore the app button opens the app. User can use default map features, check live events, read reviews, check profiles etc. But to send messages, call, post and follow they will need to login. 

2. "HOME PAGE" mainly consists off map. Map has a layer button that will filter out establishments on the map. There will be a draggable modal that consists of:
 - search bar. Click on the bar will open a keyboard and "Home 3:Search" screen. Click on the filter opens :Home 4 and Home 5: 
- Below the search bar there are stories of the people or est. you follow. If you don't follow anyone, there will be stories from your area. 
- Then there are some guides and posts from us. and some recommendations
- "Recents" will be taken from the users history, from database
- Favourites are user personal favourite places.
- "HOME 3: Search" holds the search history. And the random categories. Click on all categories will open a modal with all fixed categories.
- Search Results
